## 💡 Почему этот скилл необходим

Классическое SEO оптимизирует сайты под **PageRank** и синие ссылки в поисковой выдаче Google и Яндекса.  
**Генеративный AI-поиск (GEO / AEO) работает по совершенно иным законам:**

1. **Нейросети не используют PageRank при формировании ответа.** Модели извлекают наиболее авторитетные, доказательно плотные и структурированные предложения из полученного контекста.
2. **Исследование Принстона и Georgia Tech (KDD 2024)** доказало, что сайты с 5-й по 10-ю позицию получают **до +115% к видимости в ответах AI**, просто внедрив доказательную плотность (цифры, первоисточники, цитаты).
3. **Классический переспам ключами (Keyword Stuffing) активно вредит** (снижает вероятность цитирования на **−8%**).
4. **Позиция ответа критична (Метрика PAWC):** В силу экспоненциального затухания, первые 150 слов статьи или раздела несут в **~5 раз больший вес** для извлечения моделью, чем завершающие абзацы.

`ultimate-seo-geo` объединяет доказательную науку о цитировании в AI и строгий технический аудит поисковой оптимизации в единый, готовый к бою инструмент.

## ⚡ 5 Режимов Работы

| Режим | Триггерные фразы | Что делает |
|---|---|---|
| **1. `audit`** | `аудит сайта`, `проверь SEO`, `посчитай GEO score`, `почему упал трафик` | Параллельный аудит: Технический SEO Score (0–100) + GEO Score (0–100) с приоритизированным планом действий (P0 / P1 / P2). |
| **2. `optimize`** | `перепиши под AI`, `сделай чтобы ChatGPT цитировал`, `front-load`, `улучши PAWC` | Превращает водянистые рекламные тексты в плотные, готовые к цитированию блоки на основе формул Принстона и CMU AutoGEO. |
| **3. `schema`** | `сгенерируй JSON-LD`, `добавь микроразметку`, `rich snippets`, `FAQ schema`, `HowTo` | Создает валидный объединенный `@graph` JSON-LD блок в `<head>`, связывающий Organization, WebSite, Service/Product, FAQ и HowTo. |
| **4. `ai-files`** | `настрой llms.txt`, `исправь robots.txt для AI`, `открой доступ GPTBot` | Формирует production-ready `robots.txt` с прямым допуском AI-ботов + файл-манифест `llms.txt` в корне сайта. |
| **5. `strategy`** | `контент-план под AI`, `карта тематического авторитета`, `семантическое ядро` | Проектирует кластеры статей и лендингов, ориентированных на длинные диалоговые запросы в Perplexity и ChatGPT. |

## 📊 Научный базис и иерархия факторов цитирования

Эмпирический рейтинг техник по приросту цитируемости в генеративных движках (исследование Princeton / Georgia Tech KDD 2024):

```
┌──────────────────────────────────────────────────────────────┐
│  ТЕХНИКА ОПТИМИЗАЦИИ                ПРИРОСТ ЦИТИРОВАНИЯ      │
├──────────────────────────────────────────────────────────────┤
│  1. Прямые цитаты экспертов         +41%  ██████████████████ │
│  2. Точные цифры с единицами измер. +30%  █████████████      │
│  3. Ссылки на первоисточники / RFC  +28%  ████████████       │
│  4. Высокая беглость (Fluency)      +28%  ████████████       │
│  5. Точная терминология (Entities)  +18%  ████████           │
│  6. Легкая для понимания структура  +14%  ██████             │
│  7. Авторитетный, прямой тон        +10%  ████               │
│  8. Переспам ключевыми словами      -8%   ▼ ШТРАФУЕТСЯ       │
└──────────────────────────────────────────────────────────────┘
```

> **Золотое правило:** Комбинация **Fluency (легкость восприятия) + Statistics (конкретные цифры)** дает прирост более **+35%**, превосходя любой отдельный метод и сохраняя идеальную читаемость для живых людей.

## 🛠️ Установка и подключение

### Вариант А: Установка в Google Antigravity (Глобально)
Клонируйте или скопируйте папку в вашу глобальную директорию скиллов:

```bash
# Windows PowerShell
git clone https://github.com/Ezhuk1/ultimate-seo-geo.git "$env:USERPROFILE\.gemini\config\skills\ultimate-seo-geo"

# macOS / Linux
git clone https://github.com/Ezhuk1/ultimate-seo-geo.git ~/.gemini/config/skills/ultimate-seo-geo
```

### Вариант Б: Локально для конкретного проекта (.agents/skills)
Если вы хотите, чтобы скилл хранился в кодовой базе конкретного проекта:

```bash
mkdir -p .agents/skills
git clone https://github.com/Ezhuk1/ultimate-seo-geo.git .agents/skills/ultimate-seo-geo
```

### Вариант В: Claude Code / Cursor / Codex
Поскольку `ultimate-seo-geo` следует международному открытому стандарту `SKILL.md`, он работает во всех поддерживаемых агентах:

```bash
# Claude Code
git clone https://github.com/Ezhuk1/ultimate-seo-geo.git ~/.claude/skills/ultimate-seo-geo

# Cursor
git clone https://github.com/Ezhuk1/ultimate-seo-geo.git ~/.cursor/skills/ultimate-seo-geo
```

### 2. Переписывание текста под высокий PAWC
```text
Перепиши первый экран и блок преимуществ моего SaaS-продукта, чтобы максимизировать шанс цитирования в Perplexity и ChatGPT. Дай прямой ответ с цифрами в первых 150 словах.
```

